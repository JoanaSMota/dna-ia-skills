# Operação e gestão

Regras que valem para o trabalho inteiro, não só para o Instagram.

[Comunicação e liderança](comunicacao-lideranca/) diz como um agente passa serviço para outro. O [painel de status](painel-de-status/) avisa se o agente está trabalhando ou esperando. Nenhuma das duas cita outra skill desta biblioteca pelo nome. O mesmo vale para os [campos do funil](pipeline-campos-obrigatorios/).

Quando a Joana decide algo, a [memória](memoria-cerebro/) manda registrar no Cérebro e usar também [registrar decisão](registrar-decisao/).

[Fonte obrigatória](fonte-obrigatoria/) exige origem para todo número. O [relatório diário](relatorio-diario/) e o [envio via Laís](envio-via-lais/) citam essa regra. O relatório também cobra os itens da [regra dos 7 dias](regra-7-dias/). Essa regra começa quando a [ficha de passagem](ficha-de-passagem/) é aceita, e o alerta de prazo pede ok pelo envio via Laís.

[Usar o Dust](usar-dust/) é a regra de operar o Dust direto. A primeira conversa desse agente está em [primeiros passos](../06-onboarding-e-primeiros-passos/primeiros-passos-dust/).

| Skill | Para que serve |
| --- | --- |
| [comunicacao-lideranca](comunicacao-lideranca/) | Um pedido completo entre agentes, e uma resposta só no fim. |
| [painel-de-status](painel-de-status/) | Avisa o painel: trabalhando, esperando, terminou ou falhou. |
| [memoria-cerebro](memoria-cerebro/) | Grava documento oficial e decisão no Cérebro. |
| [registrar-decisao](registrar-decisao/) | Anota a decisão da Joana, ou confere se ela já existe. |
| [fonte-obrigatoria](fonte-obrigatoria/) | Número sem fonte vira proposta para validar. |
| [relatorio-diario](relatorio-diario/) | Relatório até 21h e a daily das 9h. |
| [envio-via-lais](envio-via-lais/) | Rascunho, ok da Joana, envio pela Laís. |
| [regra-7-dias](regra-7-dias/) | Prazo de 7 dias para kickoff e resposta a cliente. |
| [ficha-de-passagem](ficha-de-passagem/) | Passa um negócio ganho da venda para a entrega. |
| [pipeline-campos-obrigatorios](pipeline-campos-obrigatorios/) | O que todo lead precisa ter preenchido no funil. |
| [usar-dust](usar-dust/) | Cada agente usa o Dust direto, sem intermediário. |

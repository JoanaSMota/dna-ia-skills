# Design e visual

A cara das peças. O [design system](design-system-dna/) é a regra de cor, fonte e capa para carrossel, Reel, documento e fluxograma. Os stories do perfil continuam em texto, pela skill de [stories](../01-esteira-de-conteudo-instagram/stories-semanais/). O motion segue as referências da skill de [motion](../03-edicao-de-video-e-motion/motion-reels/), não esta identidade.

Os [fluxogramas](fluxogramas-visuais/) explicam um processo em imagem e seguem o design system. O [onboarding de conteúdo](../06-onboarding-e-primeiros-passos/onboarding-conteudo/) usa os modelos 01 a 05 desses fluxos. [Diagramas](diagram-design/) é uma ferramenta à parte, para organograma, linha do tempo, fluxo e outros desenhos. Nenhuma outra skill desta biblioteca cita ela pelo nome.

[Materiais em PDF](dna-materiais-pdf/) é uma etapa da esteira, hoje vetada até a Joana liberar. Ela especifica o PDF a partir de peças que já foram bem e manda seguir o design system. Não gera o arquivo final. O [fluxo da equipe](../01-esteira-de-conteudo-instagram/fluxo-da-equipe-de-conte-do/) cita esta skill.

| Skill | Para que serve |
| --- | --- |
| [design-system-dna](design-system-dna/) | Cores, fontes e checklist de qualquer peça visual da DNA. |
| [fluxogramas-visuais](fluxogramas-visuais/) | Um processo em imagem, quando a explicação tem mais de 3 passos. |
| [diagram-design](diagram-design/) | Diagramas em imagem: fluxo, linha do tempo, organograma e outros. |
| [dna-materiais-pdf](dna-materiais-pdf/) | Especificação de um PDF prático. Vetada até a Joana liberar. |

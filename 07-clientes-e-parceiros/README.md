# Clientes e parceiros

Instruções de um tipo de cliente ou de um parceiro. Não fazem parte da esteira do perfil da Joana.

Clínica: o [brief de marketing](marketing-clinica-brief/) descreve o trabalho do agente, e [getting-started](getting-started/) é a primeira conversa com o dono. Uma cita a outra.

Centro auditivo: [vendas](getting-started-vendas-centro-auditivo/) prepara indicações, visitas e follow-up. [Entrega e atendimento](getting-started-entrega-atendimento/) prepara a recepção, faltas e pós-venda. Nenhuma das duas cita outra skill desta biblioteca pelo nome.

[BNI Connect](bni-connect-1a1/) registra um 1-a-1, inclusive com membro de outro capítulo. Também não cita outra skill daqui.

| Skill | Para que serve |
| --- | --- |
| [marketing-clinica-brief](marketing-clinica-brief/) | Leads por origem, agência, pauta e canais de uma clínica. |
| [getting-started](getting-started/) | Primeira conversa com o dono da clínica. |
| [getting-started-vendas-centro-auditivo](getting-started-vendas-centro-auditivo/) | Primeira conversa do agente de vendas do centro auditivo. |
| [getting-started-entrega-atendimento](getting-started-entrega-atendimento/) | Primeira conversa do agente de recepção do centro auditivo. |
| [bni-connect-1a1](bni-connect-1a1/) | Registrar um 1-a-1 no BNI Connect. |

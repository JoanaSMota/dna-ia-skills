# Formatos de Reels

Cada pasta daqui é um jeito de contar um Reel gravado. A [orquestração](orquestra-o-formatos-criativos/) escolhe qual formato a tese pede. A [estratégia da semana](../01-esteira-de-conteudo-instagram/estrategia-formatos/) decide se aquele formato repete ou se é teste. A [edição](../03-edicao-de-video-e-motion/editor-reels/) aplica a gramática no vídeo.

A própria orquestração agrupa assim:

- Explicar ou ilustrar: tela dividida, tela verde, palestrinha, cine.
- Contar uma história: narrado, storytelling visual, bastidores.
- Contraste entre pessoas: diálogo, comparação, conflito situacional, The Office.
- Debate: experimento social, caixinha de perguntas.
- Ação e cotidiano: dinamismo, trivial.
- Conversa perto: lo-fi e, de novo, cine.

Tela do agente é um formato de teste da DNA, citado pela orquestração junto com os outros. Não é tela dividida nem tela verde.

Motion narrado e motion só com música estão na [pasta 03](../03-edicao-de-video-e-motion/), porque são animação.
